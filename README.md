# The Game Zone

The Game Zone is a Python-based application connected to a MySQL database. It provides separate options for customers and employees, allowing users to manage customer and employee information and explore different games.

## Features

- Customer registration and login
- Customer profile viewing and updating
- Employee login with admin functionality
- Add, view, and search customer and employee records
- Activate or deactivate employee accounts
- Add and search games by difficulty and number of players
- Play Snake and Ladder, Rock Paper Scissors, Tic Tac Toe, and Number Guessing

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python
- Tabulate

## How to Run

1. Install Python and MySQL.
2. Create the required MySQL database and tables.
3. Install the required Python packages:

   ```bash
   pip install mysql-connector-python tabulate getpass4
   ```

4. Configure the MySQL connection details in the Python file.
5. Run the application:

   ```bash
   python main.py
   ```
